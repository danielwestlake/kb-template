# Proposals

Sales proposals, quotes, and scopes of work submitted to prospects and clients.

## What to store here

- Full proposal documents (markdown or PDF)
- Scopes of work (SOW)
- Quotes and pricing documents
- RFP responses
- Post-outcome notes (won/lost and why)

## Naming convention

```
YYYY-MM-DD_prospect-name_proposal-slug.ext
```

## Examples

| File | Description |
|------|-------------|
| `2026-03-15_acme-corp_crm-integration-proposal.md` | CRM integration proposal for Acme Corp |
| `2026-02-01_globex_annual-support-renewal.pdf` | Annual support renewal quote for Globex |
| `2026-04-01_initech_ecommerce-replatform-sow.md` | Ecommerce replatform scope of work |

## Tips

- Include a brief outcome note at the top of each document: won/lost, decision date, and key factors.
- Proposals are a goldmine for identifying which services sell best, common objections, and pricing patterns.
- The LLM can extract themes across proposals to help refine your pitch and identify gaps.
